I wrote about [my coding workflow few months ago](/posts/agentic-coding-workflow), while some of the flow remains the same, e.g. using Claude/ChatGPT app for remote coding, kicking off new sessions on local machine or on cloud servers, how I use the models have changed a lot.

Used have buncha of skills and global rules, that is no longer the case.

# How I have been using agents nowadays

Prefer using the latest frontier lab models, e.g. Opus 5.5, GPT Sol 6.1, Astra, etc.

Prompt and let models do their thing, don't prompt the how it needs to be done, just what needs to be done. e.g. better perfromance, better UX, what new feature, etc.

No skills like 'Improve codebase', 'make codebase better', etc.

Give them access to real data, ie. data from how you use the product, not mock stuff, so models get more context and don't make up stuff.

Point them to up-to-date docs of the libraries they are using, most libraries have agent friendly docs now.

Let agent install whatever is needed to test & build the features, give them the full verfication loop. This will lead to much better results and less headaches for human review.

_**Prototype**_: ask to generate 5 or 20 prototypes ‼️ use sites/artifacts and pick one or combine multiple instead of building something then changing/iterating which is much slower.

Ask them to attach videos/screenshots, ie. real proof of the work which is also for easier human review.

Don't always need to worry about changing mind mid-session, or adding something unrelated, latest models can handle it just fine.
