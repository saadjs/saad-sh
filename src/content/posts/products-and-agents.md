Future of the internet is going to be headless.

More and more people are going to have some type of personal agent(s) like Dot, Duet, Muse, Grok Bot, etc. completing tasks on their behalf.

This would be true for businesses as well. Agents completing tasks like filing financials, customer support, operations, etc.

Alongside building the UIs, everyone needs to build MCPs, CLIs (the connectors agents use to work with apps) so any product and capability can be easily accessed thru agents as well.

So if you have an app/product/SaaS, it’s never too late build tooling around it. Instead of forcing users to be locked in, blocking agents activity, build better tools otherwise users will switch to products with better agents support.

Because I don’t want to use your agent that you are forcing me to use, instead my agent should be able to use your product.
